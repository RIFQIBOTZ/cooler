## 🧊 `SYSTEM // OVERVIEW`

**Cooler Lab** is a lightweight benchmark archive built around one thing: **making thermal data look as good as it reads.**

The project stores cooling experiments, benchmark observations, comparison results, and supporting images in a simple static web interface.

## 🌈 `RGB // VISUAL LANGUAGE`

The project uses a **dark + neon** visual direction inspired by gaming hardware, benchmark dashboards, and RGB cooling setups.

`#FF0080` **PINK**  ·  `#00E5FF` **CYAN**  ·  `#39FF14` **GREEN**  ·  `#FFD000` **YELLOW**  ·  `#8B5CF6` **PURPLE**

The colors are used as status signals rather than decoration alone:

- 🟢 **GREEN** → cooler / better result
- 🔴 **PINK** → heat / warning
- 🔵 **CYAN** → information / baseline
- 🟡 **YELLOW** → highlight / important result
- 🟣 **PURPLE** → experimental / special data

---

## 📊 `DATA // RULES`

Thermal results are experimental measurements. Results can change with:

- ambient temperature
- device and cooler hardware
- thermal paste / interface material
- mounting pressure and contact quality
- workload and test duration
- fan speed and power conditions
- measurement method

**Same cooler ≠ same result** when the test conditions change.
