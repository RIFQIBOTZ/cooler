# Cooler Lab

Thermal test notes, cooling experiments, and comparison results.

## Overview

Cooler Lab is a small static project for recording thermal tests and comparing cooling setups. The focus is readability, simple structure, and easy maintenance.

## Contents

- thermal benchmark records
- cooler comparison results
- temperature and performance notes
- supporting images
- mobile-friendly layout

## Structure

```text
cooler/
├── index.html
├── images/
└── README.md
```

## Usage

```bash
git clone https://github.com/RIFQIBOTZ/cooler.git
cd cooler
```

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

Benchmark results are experimental. They can change depending on ambient temperature, hardware, thermal paste, mounting pressure, fan speed, workload, and measurement method.
